# 💰 Hedera Virtual Wallet

A simple **virtual wallet application** built using **Node.js** and the **Hedera Hashgraph SDK**.  
This project demonstrates how to interact with the Hedera Testnet by creating accounts, checking balances, and transferring HBAR tokens.

---

## 🚀 Features

- Create a new Hedera account automatically
- Check account balance
- Transfer HBAR between accounts
- Connect securely to Hedera Testnet
- Environment-based configuration using `.env`

---

## 🛠️ Technologies Used

- Node.js
- Hedera Hashgraph SDK
- Dotenv
- JavaScript (ES6+)
